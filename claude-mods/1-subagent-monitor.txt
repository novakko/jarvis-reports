# Build the SUBAGENT MONITOR mod for Claude Code (no internet)

**Tested on Claude Code 2.1.316.** You are Claude Code on a MacBook. Build the SUBAGENT MONITOR mod below on this machine, exactly as written. The complete source is in this document, so nothing needs downloading.

## Rules

- No internet. Do not use `npm`, `npx`, `curl`, `claude plugin install` or `claude plugin marketplace`. The mod runs from a plain local folder.
- Do not change, improve or tidy the source. It already holds the requested behaviour. The only exception is step 6.
- The mod may only use the Claude models Opus, Sonnet and Haiku. Do not add any other model or provider.
- Edit nothing outside `~/.claude-mods/flightdeck` and your settings file, which is `settings.json` in `CLAUDE_CONFIG_DIR` if that is set, else `~/.claude/settings.json`.
- If an organisation policy on this machine blocks local mods, stop and tell the person. Do not work around it.

## What you are building

**Name on disk:** `flightdeck` (plugin name, command `/flightdeck`, pane id `flightdeck`). It is a modified copy of the MIT-licensed Flightdeck 0.5.1. Keep `LICENSE` and `NOTICE`.

**What the person sees.** A live dashboard pane that opens when a session starts, default layout `monitor`:
- Header: `[ CLAUDE CODE ] 🚀 SUBAGENT MONITOR (v0.7.3) ── SESSION: #TAG | TIME: m:ss | COST: $x.xx`. As the pane narrows it drops version, then session, then time. The cost stays.
- `SUBSCRIPTION USAGE` box: up to three gradient bars (cyan to magenta) with percent and time to reset. The percent turns red at 90. With no limits it says `no plan limits reported (API session)`.
- One shared frame with a section per subagent, running first, then finished newest first, up to 6, then `+N more`. Row one: `SUBAGENT_NN`, status, quoted type, `COST: $0.000`. Then rows `Model:`, `Task:`, `Skills:`, `Tokens:`.
- A `[SUBAGENT_NN] tool → target` line for up to 4 running agents (`no subagents running` when none), and a footer `flightdeck [working…|listening…]`.
- Digits 1-6 expand a card to show its skills, its last three tool calls and its answer (focus the pane with ctrl+x tab).

**The three requested changes, already in the source below:**
1. **Active is yellow, not green.** ACTIVE status is `🟡 ACTIVE` in `#fde047` (theme palette: `warning`), and so is the `[SUBAGENT_NN]` tag. Running agents in the other layouts are yellow too.
2. **Completed is slightly grey.** DONE is a plain `✓ DONE` in `#9ca3af` (theme palette: `inactive`), and the rest of a done card is drawn dim. The emoji `✅` is gone because an emoji cannot be greyed. FAILED stays red so failures stand out. In the monitor only, THINKING stays pink and IDLE stays blue; the other layouts draw every running agent yellow. A card whose last step hit max_tokens is drawn red.
3. **Skills per subagent.** When a subagent calls the Skill tool, the skill name lands on its own card, once each, in order. It shows in the monitor's `Skills:` row (`—` when none), in the compact layout's windows, in the expanded panel, and in the swimlane and mini info text, which move to a row of their own when a skill exists so that no skill is cut off. Mini shows at most 3 agents, and desktop's time-axis drawing carries no skills. Only skills run through the Skill tool are seen, and the main chat has no card, so its skills are not listed.

**Everything else that must stay:**
- Hard limit of 4 concurrent subagents. Past it the Agent tool call is refused with `4 subagents already running; wait for one to finish before starting another.` Parallel launches are decided one at a time. A running agent silent for 15 minutes stops counting. Options `maxAgents` (0 = off) and `agentStaleMinutes`.
- Model routing, option `agentRoutes`, default `general-purpose=sonnet,claude=sonnet,Explore=haiku`. It applies only when the subagent names no model, is not a fork, is an engine agent, and the parent runs Opus. An explicit model always wins.
- Estimated costs from `hooks/pricing.ts`. Unlisted models show `$—`, never a guess.
- Other layouts: `/flightdeck layout monitor|auto|compact|wide|mini`, with main, architect, gate, agents, loops, receipt and log panels. Also `/flightdeck close` and `/flightdeck reset`.
- Default palette is `pastel`, which is what the original setup uses. `theme` is an option.
- The status line entry `ctx N% · agents a/b · …`.
- A running card turns IDLE after 60 seconds of silence (120 while thinking; a long tool call stays ACTIVE until the 15-minute limit). Row one shortens on narrow panes.
- A layout set by command lasts for the session only. `/clear` empties the pane. Credentials are masked in the gate detail.
- Options, including `openOnStart` and `statusLine`, are in the `/config` menu.

**Note on tests:** the original 77-test suite is not included because of its size. `tests/adjustments.test.tsx` covers the changes above.

## Steps

Do these in order.

### 1. Check the machine

Run `claude --version`. Mods need 2.1.287 or newer, so below that, stop and tell the person. Run `claude plugin list`. If any entry is named `flightdeck` or starts `flightdeck@`, stop and ask before going on, because two copies would run at once. If `~/.claude-mods/flightdeck` already exists and has files in it, show them and ask before replacing them.

### 2. Put the files in place

The source sits at the end of this document between `<<<<<<<< FILE: <path>` and `>>>>>>>> END FILE` lines. The instructions end at the line `=== END OF INSTRUCTIONS ===`. On the file route below you do not need to read past it.


**If you only have this as pasted text**, skip that command and create each file yourself at `~/.claude-mods/flightdeck/<path>`, with its exact contents, including the last block, `.checksums.sha256`. Leave out the marker lines, the blank line between blocks and any line numbers. Copy character for character, taking care with symbols such as `●`, `▰` and `→`, and end each file with one newline.

### 3. Prove the files are exact

```sh
cd "$HOME/.claude-mods/flightdeck" && shasum -a 256 -c .checksums.sha256
```

Every line must say `OK`. On a mismatch, redo that file from this document. Never edit the checksums. Then delete `.checksums.sha256`.

### 4. Validate and test

```sh

claude plugin test "$HOME/.claude-mods/flightdeck"
```

Neither needs the mod to be turned on. The last line of validation must be `✔ Validation passed` (with or without warnings). Anything else in that output, such as problems the plugin directory refuses and missing-author or icon warnings, does not matter, as this mod is never submitted anywhere. Tests must show **6 pass, 0 fail**.

### 5. Turn it on

Find your settings file: `settings.json` in `CLAUDE_CONFIG_DIR` if that is set, else `~/.claude/settings.json`. Use your Read and Edit tools on its full absolute path. Create the file with `{}` if it is missing, and add an `env` object if it has none. In `env`, make sure `CLAUDE_CODE_PLUGIN_DIRS` includes the absolute path of the mod folder, with `~` expanded, such as `/Users/<name>/.claude-mods/flightdeck`. If the variable already has a value, append with a `:` and keep what is there. Do not add a duplicate. Change nothing else, and leave the file as valid JSON.

Example: `"env": { "CLAUDE_CODE_PLUGIN_DIRS": "/Users/<name>/.claude-mods/flightdeck" }`

### 6. Only if step 4 failed

If the checksums passed but validation or a test failed, this Claude Code build differs from 2.1.316. The API types at `~/.claude-mods/flightdeck/.claude-plugin/types/claude-code/index.d.ts` appear only once the mod has loaded, so they are normally absent; without them, work from the failure output alone. Make the smallest fix that keeps the behaviour above, and rerun step 4. List every change in your report. If you cannot get it passing, say so plainly and do not do step 5.

### 7. Report

Tell the person:
- the checksum, validation and test results, and whether step 6 was needed
- to start a new Claude Code session, because a running one will not load the mod
- what they should see: a pane titled Flightdeck opens by itself and its header starts `[ CLAUDE CODE ] 🚀 SUBAGENT MONITOR` and ends with `COST:`. The version shows only from about 93 columns. On a narrow terminal the pane waits; run `/flightdeck`.

/** A stored object merged over its defaults, so a value saved under an older shape still reads. */

  isObject(stored) ? ({ ...def, ...stored } as T) : def

/** A stored list, or empty when what is stored is not a list. */

export const DEFAULT_ROUTES = 'general-purpose=sonnet,claude=sonnet,Explore=haiku'

/** `type=model,type=model` read leniently: a piece without both sides is skipped. */
const parseRoutes = (s: string): Record<string, string> => {
  const out: Record<string, string> = {}
  for (const piece of s.split(',')) {
    const [type = '', model = ''] = piece.split('=').map(x => x.trim())
    if (type && model) out[type] = model
  }
  return out
}

const safeRegExp = (source: string, fallback: string) => {
  try {
    return new RegExp(source || fallback, 'i')
  } catch {
    return new RegExp(fallback, 'i')
  }
}

/** The plugin's `/config` values, read leniently: anything malformed falls back to the default. */
export const parseConfig = (o: Readonly<Record<string, unknown>>): Config => {
  const str = (k: string, d: string) => (typeof o[k] === 'string' && o[k] !== '' ? (o[k] as string) : d)
  const bool = (k: string, d: boolean) => (typeof o[k] === 'boolean' ? (o[k] as boolean) : d)
  const panels = str('panels', PANELS.join(','))
    .split(',')
    .map(s => s.trim())
    .filter((p): p is Panel => (PANELS as readonly string[]).includes(p))
  const layout = str('layout', 'monitor')
  const max = typeof o.maxCards === 'number' ? Math.round(o.maxCards) : 6
  const whole = (k: string, d: number) => (typeof o[k] === 'number' && Number.isFinite(o[k]) ? Math.round(o[k] as number) : d)
  const cols = typeof o.paneColumns === 'number' && Number.isFinite(o.paneColumns) ? Math.round(o.paneColumns) : 66
  return {
    architect: safeRegExp(str('architectPattern', ''), 'advisor|architect'),
    architectLabel: str('architectLabel', 'ARCHITECT'),
    gateLabel: str('gateLabel', 'GATE'),
    panels: panels.length > 0 ? [...new Set(panels)] : [...PANELS],
    motion: str('motion', 'while-active') !== 'off',
    moments: bool('moments', true),
    matchDescriptions: bool('matchDescriptions', false),
    maxCards: Math.min(6, Math.max(1, max)),
    // An empty string turns routing off; only a missing or non-string value takes the default.
    agentRoutes: parseRoutes(typeof o.agentRoutes === 'string' ? o.agentRoutes : DEFAULT_ROUTES),
    // 0 lifts the limit on concurrent subagents.
    maxAgents: Math.min(50, Math.max(0, whole('maxAgents', 4))),
    agentStaleMs: Math.max(1, whole('agentStaleMinutes', 15)) * 60_000,
    // The body clamps its drawing at 40 columns, so a narrower dock would only clip it.
    paneColumns: Math.max(40, cols),
    layout: layout === 'compact' || layout === 'wide' || layout === 'mini' || layout === 'auto' ? layout : 'monitor',
    palette: str('palette', 'pastel') === 'theme' ? 'theme' : 'pastel',
    openOnStart: bool('openOnStart', true),
    statusLine: bool('statusLine', true),
  }
}

/** `claude-opus-5-5` → `Opus 5.5`; anything else is shown as given. */
/**
 * A model id as people say it, from any provider's spelling: `claude-opus-5-5[1m]` → `Opus 5.5 1M`,
 * `us.anthropic.claude-sonnet-4-5-20250929-v1:0` → `Sonnet 4.5`, `claude-3-5-haiku-20241022` →
 * `Haiku 3.5`. Anything else is shown as given, cut to 22 characters.
 */
export const prettyModel = (id: string) => {
  if (!id) return '—'
  const cap = (f: string) => f.charAt(0).toUpperCase() + f.slice(1)
  const big = /\[1m\]|-1m\b/i.test(id) ? ' 1M' : ''
  const now = /claude-([a-z]+)-(\d+)(?:-(\d{1,2}))?(?:-\d{8})?(?![\d])/i.exec(id)
  if (now?.[1] && !/^\d/.test(now[1])) return `${cap(now[1].toLowerCase())} ${now[2]}${now[3] ? `.${now[3]}` : ''}${big}`
  const old = /claude-(\d+)(?:-(\d))?-([a-z]+)/i.exec(id)
  if (old?.[3]) return `${cap(old[3].toLowerCase())} ${old[1]}${old[2] ? `.${old[2]}` : ''}${big}`
  return shorten(id, 22)
}

export const shorten = (s: string, n: number) => {
  const one = s.replace(/\s+/g, ' ').trim()
  return n <= 0 ? '' : one.length > n ? `${one.slice(0, Math.max(0, n - 1)).trimEnd()}…` : one
}

export const kTokens = (n: number) =>
  n >= 1_000_000 ? `${(n / 1_000_000).toFixed(1)}M` : n >= 1000 ? `${Math.round(n / 1000)}k` : String(n)

export const fmtDuration = (ms: number) => {
  const s = Math.max(0, Math.round(ms / 1000))
  if (s < 60) return `${s}s`
  const m = Math.floor(s / 60)
  return m < 60 ? `${m}m${String(s % 60).padStart(2, '0')}s` : `${Math.floor(m / 60)}h${String(m % 60).padStart(2, '0')}m`
}

/** A running clock as the live cards draw it: m:ss, or XhYY past an hour. */

  const s = Math.max(0, Math.floor(ms / 1000))
  const m = Math.floor(s / 60)
  return m < 60 ? `${m}:${String(s % 60).padStart(2, '0')}` : `${Math.floor(m / 60)}h${String(m % 60).padStart(2, '0')}`
}

export const fmtClock = (ms: number) => (ms > 0 ? new Date(ms).toTimeString().slice(0, 8) : '--:--:--')

export const fmtUsd = (n: number) => (n >= 100 ? `$${Math.round(n)}` : `$${n.toFixed(2)}`)

/** Whether a measurement says nothing the stored usage does not: the write (and its redraw) is skipped. */
export const isSameMeasure = (u: Usage, m: Pick<Usage, 'pct' | 'tokens' | 'window' | 'costUsd' | 'limits'>) =>
  u.pct === m.pct &&
  u.tokens === m.tokens &&
  u.window === m.window &&
  u.costUsd === m.costUsd &&
  u.limits.length === m.limits.length &&
  u.limits.every((l, i) => l.kind === m.limits[i]?.kind && l.pct === m.limits[i]?.pct && (l.resetsAt ?? null) === (m.limits[i]?.resetsAt ?? null))

const STOPS = [[0x5e, 0xea, 0xd4], [0x93, 0xc5, 0xfd], [0xc0, 0x84, 0xfc], [0xe8, 0x79, 0xf9]] as const

/** Cell `i` of a `width`-cell bar, along a cyan → blue → violet → magenta gradient, as `#rrggbb`. */
export const gradientCell = (i: number, width: number) => {
  const t = width <= 1 ? 0 : Math.min(1, Math.max(0, i / (width - 1))) * (STOPS.length - 1)
  const k = Math.min(STOPS.length - 2, Math.floor(t))
  const a = STOPS[k]!
  const b = STOPS[k + 1]!
  return `#${[0, 1, 2].map(c => Math.round(a[c]! + (b[c]! - a[c]!) * (t - k)).toString(16).padStart(2, '0')).join('')}`
}

/**
 * How soon a request began to answer: from when it was sent to its first piece of response; null when
 * none came. No output rate: the reported tokens include thinking, which may arrive unstreamed before
 * that first piece, so tokens over the visible stream read in the thousands per second.
 */
export const stepSpeed = (sentAt: number, firstAt: number | null) => (firstAt === null ? null : { ttftMs: Math.max(0, firstAt - sentAt) })

/** `ttft 0.8s`. */
export const fmtSpeed = (s: { ttftMs: number }) => `ttft ${(s.ttftMs / 1000).toFixed(1)}s`

/** The compaction window a context breakdown reports: its `rawMaxTokens` when auto-compaction is on and that is smaller than the model's `window`; else null. */
export const compactWindowOf = (b: { rawMaxTokens: number; isAutoCompactEnabled: boolean } | null | undefined, window: number): number | null =>
  b && b.isAutoCompactEnabled && b.rawMaxTokens > 0 && b.rawMaxTokens < window ? b.rawMaxTokens : null

/**
 * What the context gauge measures: the compaction window when one is set smaller than the model's,
 * else the model's window, and the fill of it from the real `tokens` reading. No gauge (null) without one.
 */
export const contextFill = (u: Pick<Usage, 'tokens' | 'window' | 'compactWindow'>): { pct: number | null; window: number } => {
  const window = u.compactWindow !== null && u.compactWindow > 0 && u.compactWindow < u.window ? u.compactWindow : u.window
  return { window, pct: u.tokens !== null && window > 0 ? (u.tokens * 100) / window : null }
}

/** Reads of the compaction window that may miss (no session bound yet) before a model window stops asking. */
export const COMPACT_TRIES = 3

/**
 * A measurement of model window `window`: whether it reads the compaction window (not read for this
 * window yet, fewer than COMPACT_TRIES misses), and the usage with that read claimed. A new window
 * starts its misses afresh.
 */
export const claimCompactRead = (u: Usage, window: number): { usage: Usage; isClaimed: boolean } => {
  const misses = u.window === window ? u.compactMisses : 0
  const isClaimed = window > 0 && u.compactFor !== window && misses < COMPACT_TRIES
  return { usage: { ...u, compactFor: isClaimed ? window : u.compactFor, compactMisses: misses }, isClaimed }
}

/**
 * The usage after a compaction-window read for model window `window`. Dropped when a newer claim took
 * its place (a model switch); a read that failed or came back with no breakdown is a miss, asked
 * again at the next measurement.
 */
export const afterCompactRead = (
  u: Usage,
  window: number,
  b: { rawMaxTokens: number; isAutoCompactEnabled: boolean } | null | undefined,
): Usage =>
  u.compactFor !== window
    ? u
    : b
      ? { ...u, compactWindow: compactWindowOf(b, window), compactMisses: 0 }
      : { ...u, compactWindow: null, compactFor: 0, compactMisses: u.compactMisses + 1 }

/** A new main-loop model may compact in another window (`modelSettings`): read afresh at the next measurement. */
export const forgetCompactRead = (u: Usage): Usage => ({ ...u, compactWindow: null, compactFor: 0, compactMisses: 0 })

/** A gauge of `width` cells: ▰ filled, ▱ empty. */
export const gauge = (pct: number, width: number) => {
  const full = Math.max(0, Math.min(width, Math.round((pct / 100) * width)))
  return { on: '▰'.repeat(full), off: '▱'.repeat(width - full) }
}

/** A rate-limit reading as the pane keeps it, its ISO reset time turned into ms since the epoch. */
export const limitOf = (r: { kind: string; percentUsed: number; resetsAt?: string }) => {
  const at = r.resetsAt ? Date.parse(r.resetsAt) : NaN
  return { kind: r.kind, pct: r.percentUsed, resetsAt: Number.isFinite(at) ? at : null }
}

/** Time left until a window resets, its two largest units: `25m`, `3h10m`, `4d2h`; empty when unknown or past. */
export const fmtResetIn = (resetsAt: number | null | undefined, now: number) => {
  if (resetsAt === null || resetsAt === undefined || resetsAt <= now) return ''
  const m = Math.max(1, Math.floor((resetsAt - now) / 60_000))
  const d = Math.floor(m / 1440)
  const h = Math.floor((m % 1440) / 60)
  if (d > 0) return `${d}d${h}h`
  return h > 0 ? `${h}h${String(m % 60).padStart(2, '0')}m` : `${m}m`
}

/** A rate-limit window's short name: `five_hour` → `5h`, `seven_day_opus` → `7d opus`. */
export const limitLabel = (kind: string) =>
  kind
    .replace(/five[_ -]?hours?/i, '5h')
    .replace(/seven[_ -]?days?/i, '7d')
    .replace(/[_-]+/g, ' ')
    .trim()

  [/(authorization\s*[:=]\s*)(bearer\s+|basic\s+)?\S+/gi, '$1$2•••'],
  [/\b(bearer)\s+[A-Za-z0-9._~+/-]{8,}=*/gi, '$1 •••'],

  [/((?:api[_-]?key|access[_-]?token|token|secret|password|passwd|pwd)\s*[=:]\s*)("[^"]*"|'[^']*'|\S+)/gi, '$1•••'],
  [/(--(?:token|password|api-key|secret)[= ])\S+/gi, '$1•••'],
  [/(\b[A-Z][A-Z0-9_]*(?:KEY|TOKEN|SECRET|PASSWORD)=)\S+/g, '$1•••'],
  [/(\b[a-z][a-z0-9+.-]*:\/\/[^\s/:@]+:)[^\s@]+@/gi, '$1•••@'],
]

/** What the gate drill-down may store: credentials masked before anything is written to state. */
export const redact = (s: string) => SECRETS.reduce((t, [re, to]) => t.replace(re, to), s)

const FILE_TOOLS = new Set(['Read', 'Edit', 'Write', 'NotebookEdit', 'Glob', 'Grep'])
const SHELL_TOOLS = new Set(['Bash', 'PowerShell'])
export const EDIT_TOOLS = new Set(['Edit', 'Write', 'NotebookEdit'])

export const bucketOf = (tool: string): Bucket =>
  FILE_TOOLS.has(tool) ? 'file' : SHELL_TOOLS.has(tool) ? 'shell' : 'other'

/** One line saying what a call was about: its command, path or pattern; redacted. */
export const describeInput = (tool: string, input: unknown) => {
  const i = isObject(input) ? input : {}
  const path = typeof i.file_path === 'string' ? i.file_path.split(/[\\/]/).slice(-2).join('/') : ''
  const what =
    typeof i.command === 'string'
      ? i.command
      : path || (typeof i.pattern === 'string' ? i.pattern : typeof i.url === 'string' ? i.url : typeof i.description === 'string' ? i.description : '')
  return redact(what ? `${tool} → ${what}` : tool)
}

/** Keeps the last `max` checks, but never drops a pending ask: its settle must still find it. */
export const trimRecent = (list: Check[], max: number): Check[] => {
  let extra = list.length - max
  if (extra <= 0) return list
  const out: Check[] = []
  for (const c of list) {
    if (extra > 0 && c.verdict !== 'ask') {
      extra -= 1
      continue
    }
    out.push(c)
  }
  return out.slice(-max * 2)
}

export const recordCheck = (g: Gate, c: Check): Gate => {
  const t = g.totals[c.bucket]
  return {
    recent: trimRecent([...g.recent, c], 80),
    totals: { ...g.totals, [c.bucket]: { ...t, [c.verdict]: t[c.verdict] + 1 } },
  }
}

/** An `ask` settled by the call that followed it: it ran (cleared) or was refused (deny). */
export const settleCheck = (g: Gate, id: string, didRun: boolean): Gate => {
  const c = g.recent.find(r => r.id === id && r.verdict === 'ask')
  if (!c) return g
  const verdict = didRun ? 'cleared' : 'deny'
  const t = g.totals[c.bucket]
  return {
    recent: g.recent.map(r => (r === c ? { ...r, verdict } : r)),
    totals: { ...g.totals, [c.bucket]: { ...t, ask: Math.max(0, t.ask - 1), [verdict]: t[verdict] + 1 } },
  }
}

export const gateSummary = (g: Gate) => {
  const all = (['file', 'shell', 'other'] as const).reduce(
    (s, k) => ({
      rule: s.rule + g.totals[k].rule,
      ask: s.ask + g.totals[k].ask,
      cleared: s.cleared + g.totals[k].cleared,
      deny: s.deny + g.totals[k].deny,
    }),
    { ...ZERO },
  )
  return { ...all, total: all.rule + all.ask + all.cleared + all.deny }
}

/**
 * The turn after one tool call. Errors count in the main loop only (a subagent's failure is its
 * own); edits count from every loop, so delegated work still reaches "before done".
 */
export const afterCall = (t: Turn, c: { inSubagent: boolean; hasFailed: boolean; isEdit: boolean }): Turn => ({
  ...t,
  errorStreak: c.inSubagent ? t.errorStreak : c.hasFailed ? t.errorStreak + 1 : 0,
  errors: t.errors + (!c.inSubagent && c.hasFailed ? 1 : 0),
  edits: t.edits + (c.isEdit ? 1 : 0),
})

/** Which of the architect's three moments a consult falls at: an inference over this turn so far. */
export const momentOf = (t: Pick<Turn, 'edits' | 'errorStreak'>): Moment =>
  t.errorStreak >= 2 ? 'error repeats' : t.edits === 0 ? 'before a plan' : 'before done'

export const startConsult = (a: Architect, c: { id: string; at: number; moment: Moment; via: string }): Architect =>
  a.consults.some(x => x.id === c.id) ? a : { ...a, consults: [...a.consults, { ...c, endAt: null }].slice(-40) }

/** Ends the open consult (the latest without an end), or the one named. */
export const endConsult = (a: Architect, at: number, advice: string | null, id?: string): Architect => {
  const open = [...a.consults].reverse().find(c => c.endAt === null && (id === undefined || c.id === id))
  return {
    ...a,
    consults: a.consults.map(c => (c === open ? { ...c, endAt: at } : c)),
    lastAdvice: advice ?? a.lastAdvice,
  }
}

export const isAdvising = (a: Architect) => a.consults.some(c => c.endAt === null)

/** A one-row timeline of consults across `width` cells: ◆ a consult, ━ while it ran. */
export const consultTimeline = (a: Architect, now: number, width: number) => {
  if (a.consults.length === 0 || width < 4) return '─'.repeat(Math.max(0, width))
  const first = a.consults[0]?.at ?? now
  const span = Math.max(1, now - first)
  const cells = Array.from({ length: width }, () => '─')
  for (const c of a.consults) {
    const from = Math.min(width - 1, Math.floor(((c.at - first) / span) * (width - 1)))
    const to = Math.min(width - 1, Math.floor((((c.endAt ?? now) - first) / span) * (width - 1)))
    for (let i = from + 1; i <= to; i += 1) cells[i] = '━'
    cells[from] = '◆'
  }
  return cells.join('')
}

  errors: t.errors,
  costDelta: o.costNow !== null && t.costAtStart !== null && o.costNow - t.costAtStart >= 0.005 ? o.costNow - t.costAtStart : null,
  reason: o.reason,
})

type StepUsage = { input_tokens?: number; cache_read_input_tokens?: number; cache_creation_input_tokens?: number; output_tokens?: number } | null

/** A card after one of its model requests: its context is the latest step's whole input; output, input and cache tokens and the estimated cost add up. */
export const applyStep = (
  c: AgentCard,
  s: { model: string; usage: StepUsage; stopReason: string | null; effort?: unknown; at?: number },
): AgentCard => {
  const u = s.usage ?? {}
  const t = { input: u.input_tokens ?? 0, cacheRead: u.cache_read_input_tokens ?? 0, cacheWrite: u.cache_creation_input_tokens ?? 0, output: u.output_tokens ?? 0 }
  const ctx = t.input + t.cacheRead + t.cacheWrite
  // A spawn model may be an alias ('sonnet') with no price: the step's real id replaces it.
  const model = c.model && priceOf(c.model) ? c.model : s.model || c.model
  return {
    ...c,
    model,
    steps: c.steps + 1,
    ctx: ctx > 0 ? ctx : c.ctx,
    out: c.out + t.output,
    inTok: c.inTok + t.input,
    cacheRead: c.cacheRead + t.cacheRead,
    cacheWrite: c.cacheWrite + t.cacheWrite,
    cost: c.cost + (costOf(model, t) ?? 0),
    effort: s.effort === undefined || s.effort === null ? c.effort : String(s.effort),
    lastAt: s.at ?? c.lastAt,
    lastStop: s.stopReason,
  }
}

export const resumeCard = (c: AgentCard): AgentCard => ({ ...c, status: 'running', endedAt: null })

/**
 * A spawned card joins the list. An id already there is that agent resumed: its card runs again
 * where it stands, with its tallies and the new task and model, so no two cards share keys.

export const addCard = (cards: AgentCard[], card: AgentCard): AgentCard[] =>
  cards.some(c => c.id === card.id)

    : [...cards, card].slice(-24)

export const stepLoop = (loops: Loop[], id: string, at: number): Loop[] => {
  const found = loops.find(l => l.id === id)
  const next = found
    ? loops.map(l => (l === found ? { ...l, steps: l.steps + 1, lastAt: at } : l))
    : [...loops, { id, steps: 1, firstAt: at, lastAt: at, isDone: false }]
  return next.slice(-60)
}

export const LOOP_ACTIVE_MS = 15_000
export const isLoopActive = (l: Loop, now: number) => !l.isDone && now - l.lastAt < LOOP_ACTIVE_MS

/** Swimlane geometry: each agent's bar on one shared axis from the first spawn to now. */
export const lanes = (cards: AgentCard[], now: number, width: number) => {
  const start = Math.min(...cards.map(c => c.spawnedAt).filter(n => n > 0), now)
  const span = Math.max(1, now - start)
  return cards.map(c => {
    const from = Math.floor(((Math.max(c.spawnedAt, start) - start) / span) * width)
    const to = Math.max(from + 1, Math.ceil((((c.endedAt ?? now) - start) / span) * width))
    return { id: c.id, before: Math.min(from, width), bar: Math.min(to, width) - Math.min(from, width), after: width - Math.min(to, width) }
  })
}

/** How many log lines fit: what the other panels leave, never fewer than 4 nor more than 8. */
export const logRows = (bodyRows: number, used: number) => Math.max(4, Math.min(8, bodyRows - used - 3))

/** Legend items that fit on one row of `width` cells, in order; the rest are dropped. */
export const fitLegend = <T extends { label: string }>(items: T[], width: number) => {
  const out: T[] = []
  let used = 0
  for (const it of items) {
    const w = it.label.length + 4
    if (used + w > width) break
    out.push(it)
    used += w
  }
  return out
}

/** The cells a string takes in a terminal: one per character. */
export const cellWidth = (s: string) => [...s].length

/**
 * How many pieces of a line fit in `room` cells, in order from the start: each piece is `lead` extra cells
 * then `width`, and pieces sit `gap` cells apart. The rest are left out, as the legend's items are.
 */
export const piecesThatFit = (pieces: readonly { width: number; lead?: number }[], room: number, gap: number) => {
  let used = 0
  for (let i = 0; i < pieces.length; i += 1) {
    const p = pieces[i]!
    const next = used + (i > 0 ? gap : 0) + (p.lead ?? 0) + p.width
    if (next > room) return i
    used = next
  }
  return pieces.length
}

/**
 * How many marks (■ ✗ ● ○ ✓) a row of `cells` columns holds. A terminal draws each mark in one
 * cell; a graphical surface draws them wider (■ measured about 1.4 cells on the desktop app), so
 * there a row holds fewer and its newest marks still show.
 */
export const marksIn = (cells: number, isTerminal: boolean) => (isTerminal ? cells : Math.floor(cells / 1.5))

/** A title split over two rows at a word boundary: `first` cells on row one, `rest` on row two. */
export const titleLines = (title: string, first: number, rest: number): [string, string] => {
  const t = title.replace(/\s+/g, ' ').trim()
  if (t.length <= first) return [t, '']
  const cut = t.lastIndexOf(' ', first)
  const at = cut > 0 ? cut : first
  return [t.slice(0, at).trim(), shorten(t.slice(at), rest)]
}

/**
 * What a turn's opening text was, for the log: the person's words, or for a turn the engine
 * opened with a tagged message (a subagent's hand-back, a task notification), that message's kind.
 */
export const promptLine = (text: string): { who: string; text: string } => {
  const tag = /^\s*<([a-z][\w-]*)/i.exec(text)?.[1]
  if (!tag) return { who: 'you', text: shorten(text, 70) }
  const from = /\bfrom="([^"]+)"/.exec(text)?.[1]
  return { who: 'engine', text: shorten(`${tag.replace(/[-_]/g, ' ')}${from ? ` from ${from.slice(0, 8)}` : ''}`, 70) }
}

/**
 * A subagent's hand-back message: who sent it and the first line of what it said. The report
 * follows a framing header in the message; without one, the first line after the opening tag.
 */
export const handbackOf = (text: string): { from: string; body: string } | null => {
  const from = /^\s*<agent-message\s+from="([^"]+)"/.exec(text)?.[1]
  if (!from) return null
  const afterHeader = text.split(/The report follows:\s*\n/)[1]
  const rest = afterHeader ?? text.replace(/^\s*<agent-message[^>]*>/, '')
  const body =
    rest
      .split('\n')
      .map(l => l.trim())
      .find(l => l && !l.startsWith('[') && !l.startsWith('<') && !l.startsWith('</')) ?? ''
  return body ? { from, body } : null
}

/** The advice line a pane shows for a report: its first real line, markdown markers stripped, cut to 160. */
export const adviceLine = (report: string) => {
  const first = report.split('\n').map(l => l.trim()).find(l => l && !l.startsWith('[') && !l.startsWith('<')) ?? ''
  return shorten(first.replace(/\*\*|__/g, '').replace(/^[#>*\s-]+/, ''), 160)
}

export const IDLE_MS = 60_000
export const THINKING_IDLE_MS = 120_000

/** What a subagent is doing now, from the phase its hooks last noted. A running card silent too long is IDLE; a tool call may run long, thinking may not. */
export const cardStatus = (c: AgentCard, now: number, staleMs: number) => {
  if (c.status === 'done') return { word: 'DONE', glyph: '✓', tone: 'done' } as const
  if (c.status === 'failed') return { word: 'FAILED', glyph: '❌', tone: 'failed' } as const
  if (c.status !== 'running') return { word: 'STOPPED', glyph: '⏹', tone: 'stopped' } as const
  if (!isLive(c, now, staleMs)) return { word: 'IDLE', glyph: '💤', tone: 'idle' } as const
  if (c.phase === 'thinking' && now - (c.lastAt || c.spawnedAt) < THINKING_IDLE_MS) return { word: 'THINKING', glyph: '🧠', tone: 'thinking' } as const
  if (c.phase === 'tool' || now - (c.lastAt || c.spawnedAt) < IDLE_MS) return { word: 'ACTIVE', glyph: '🟡', tone: 'active' } as const
  return { word: 'IDLE', glyph: '💤', tone: 'idle' } as const
}

/**
 * The model to force on a spawn, or null to leave it. An explicit `model`, a fork, a type with no
 * route and a parent that is not Opus are never rerouted.
 * Only agents built into the engine are routed: an unset model means a user's agent file's own.
 */
export const routeModel = (
  routes: Record<string, string>,
  s: { subagentType: string; provider: { plugin: string }; model?: string | undefined; parentModel: string; fork?: boolean | undefined },
): string | null =>

/** Running = marked running and active within `staleMs`: a crashed agent that never reported stops counting. */
export const isLive = (c: AgentCard, now: number, staleMs: number) => c.status === 'running' && now - (c.lastAt || c.spawnedAt) < staleMs

export const agentTotals = (cards: AgentCard[], now: number, staleMs: number) => {
  const priced = cards.filter(c => priceOf(c.model))
  return {
    running: cards.filter(c => isLive(c, now, staleMs)).length,
    total: cards.length,
    inTok: cards.reduce((n, c) => n + c.inTok + c.cacheRead + c.cacheWrite, 0),
    out: cards.reduce((n, c) => n + c.out, 0),
    // Null when no card's model is priced; unpriced models add nothing.
    cost: priced.length > 0 ? priced.reduce((n, c) => n + c.cost, 0) : null,
  }
}

/**
 * One line saying a subagent's model and tokens, fitted to `room` cells: the full wording, then a
 * short form, then cut with an ellipsis. The model is never dropped.
 */
export const agentInfo = (c: AgentCard, room: number) => {
  const model = prettyModel(c.model)
  const skills = c.skills.length > 0 ? ` · ${c.skills.join(' ')}` : ''
  const full = c.steps > 0 ? `${model} ctx ${kTokens(c.ctx)} out ${kTokens(c.out)}${skills}` : `${model} starting${skills}`
  const short = c.steps > 0 ? `${model} ${kTokens(c.ctx)}/${kTokens(c.out)}${skills}` : `${model}${skills}`
  return shorten(full.length <= room ? full : short, room)
}

/**
 * Limit on concurrent subagents. `admit` decides under a queue: a parallel launch's calls are decided
 * one after another, each seeing the reservations of those before it, so the one past the limit is
 * refused however many arrive at once. A reservation lasts until `release` (the spawn recorded its
 * card, or the call ended), and lapses after RESERVATION_MS so a hung call cannot hold a slot.
 */
export const RESERVATION_MS = 10 * 60_000
export const makeSpawnGate = () => {
  const reserved = new Map<string, number>()
  let queue: Promise<unknown> = Promise.resolve()
  return {
    admit(id: string, limit: number, load: () => Promise<{ running: number; now: number }>): Promise<boolean> {
      const run = queue.then(async () => {
        const { running, now } = await load()
        for (const [k, at] of reserved) if (now - at > RESERVATION_MS) reserved.delete(k)
        if (limit > 0 && running + reserved.size >= limit) return false
        reserved.set(id, now)
        return true
      })
      queue = run.catch(() => undefined)
      return run
    },
    release: (id: string) => void reserved.delete(id),
    pending: () => reserved.size,
  }
}

export const spawnDenied = (limit: number) => `${limit} subagents already running; wait for one to finish before starting another.`

const fmt = (ms: number) => {
  const s = Math.max(0, Math.floor(ms / 1000))
  const m = Math.floor(s / 60)
  return m < 60 ? `${m}:${String(s % 60).padStart(2, '0')}` : `${Math.floor(m / 60)}h${String(m % 60).padStart(2, '0')}`

    // A fresh reading from the hooks module: restart the local count from it.
    ref.lastNow = props.now
    ref.base = (props.endAt ?? props.now) - props.since
    ref.ticks = 0

      if (ref.isRunning) {
        ref.ticks += 1
        surface.setState({ ref })

// A connector drawn on the surface's own frame clock: packets travel along it while `active`,
// and it rests as a plain dim line otherwise. Only this region redraws; the pane does not.
import type { ClientModule, RenderChildren } from 'claude-code'

type Props = {
  active: boolean
  width: number
  color: string
  dim: string
  /** Cells where a branch drops (┬); the rest of the line is ─. */
  marks: number[]
  /** Draw ┴ instead of ┬ at the marks: a merge into what is below. */
  isMerge: boolean
}

type Ref = { phase: number; active: boolean }
type State = { ref: Ref }

const STEP_MS = 110
/** Dashes drawn past the line's end and clipped by its box, so the right end is the box's edge. */
const SPARE = 4

const Rail: ClientModule<Props, State> = (props, surface) => {
  const { Box, Text } = surface.elements
  const ref = surface.state?.ref ?? { phase: 0, active: props.active }
  ref.active = props.active
  if (surface.state === undefined) {
    surface.setState({ ref })
    surface.every(STEP_MS, () => {
      if (ref.active) {
        ref.phase += 1
        surface.setState({ ref })
      }
    })
  }

  const width = Math.max(1, surface.columns || props.width)
  const cells = Array.from({ length: width + SPARE }, () => '─')
  for (const m of props.marks) if (m >= 0 && m < width) cells[m] = props.isMerge ? '┴' : '┬'

  // A graphical surface draws text in a proportional face, where ─ ● • and bold differ in width, so as
  // the packets moved the line's length changed and its right end jittered. Drawn in the surface's
  // monospaced face (whose advance is what a cell is there) each glyph is one cell, and the line sits in
  // a box of its width that clips the spare dashes: its right end is that edge, every frame.
  const line = (children: RenderChildren) => (
    <Box width={width} overflow="hidden">
      <Box flexShrink={0}>{children}</Box>
    </Box>
  )

  if (!props.active) {
    return line(
      <Text color={props.dim} mono>
        {cells.join('')}
      </Text>,
    )
  }

  // Two packets per 24 cells, a bright head and a trailing dot, moving left to right.
  const lit = new Map<number, string>()
  for (let base = 0; base < width + 24; base += 24) {
    const head = (base + ref.phase) % (width + 24)
    if (head < width) lit.set(head, '●')
    if (head - 1 >= 0 && head - 1 < width) lit.set(head - 1, '•')
  }
  // Runs, not cells: consecutive cells of one kind share a Text, a handful of nodes per frame.
  const runs: { text: string; isLit: boolean }[] = []
  cells.forEach((ch, i) => {
    const isLit = lit.has(i)
    const last = runs[runs.length - 1]
    const glyph = lit.get(i) ?? ch
    if (last && last.isLit === isLit) last.text += glyph
    else runs.push({ text: glyph, isLit })
  })
  return line(
    runs.map(r => (
      <Text color={r.isLit ? props.color : props.dim} bold={r.isLit} mono>
        {r.text}
      </Text>
    )),
  )
}

export default Rail

      return { text: 'Flightdeck closed.' }
    }
    if (verb === 'reset') {
      await resetAll($)
      await refreshStatus($, cfg)
      return { text: 'Flightdeck reset.' }
    }
    if (verb === 'layout') {
      const layout: Layout | null = arg === 'compact' || arg === 'wide' || arg === 'auto' || arg === 'mini' || arg === 'monitor' ? arg : null
      if (!layout) return { text: 'Usage: /flightdeck layout monitor|auto|compact|wide|mini' }
      await update($, view, v => ({ ...normalize(DEFAULT_VIEW, v), layout }))
      const opened = await openPane($, cfg)
      return { text: opened.isPlaced ? `Flightdeck layout: ${layout}.` : `Layout set to ${layout}; the pane is not shown yet: ${opened.reason}` }
    }
    const opened = await openPane($, cfg)
    if (!opened.isPlaced) return { text: `Flightdeck is not shown yet: ${opened.reason}` }
    return { text: 'Flightdeck opened. Focus it with ctrl+x tab; 1-6 expand cards, f/s/o open the gate rows.' }
  })

  on('classic.UserPromptSubmit', async ($, e, next) => {
    await noteMode($, e.permission_mode)
    return next(e)
  })

  on('agent.offer', async ($, e, next) => {
    const offered = await next(e)
    if (cfg.architect.test(e.agent) || (cfg.matchDescriptions && cfg.architect.test(e.description))) {
      await update($, roster, r => {
        const x = normalize(DEFAULT_ROSTER, r)
        return x.architectTypes.includes(e.agent) ? x : { architectTypes: [...listOf<string>(x.architectTypes), e.agent].slice(-20) }
      })
    }
    return offered
  })

  on('turn.start', async ($, e, next) => {
    // A subagent's turn (its spawn, or a resume by SendMessage) is its card's, not the main turn's.
    if (e.agentId !== undefined) return next(e)
    const [now, cost] = await Promise.all([$.clock.now(), costNow($)])
    await update($, turn, () => ({ ...DEFAULT_TURN, startedAt: now, costAtStart: cost }))
    await update($, main, m => ({ ...normalize(DEFAULT_MAIN, m), isRunning: true }))
    // A background architect's report reaches the main loop as the text opening this turn. The
    // SubagentHandback tool call (in tool.call) normally carries it first; this is the fallback.
    const back = e.text ? handbackOf(e.text) : null
    const a = back ? await getArchitect($) : null
    if (back && a && a.ids.includes(back.from)) {
      const advice = adviceLine(back.body)
      if (advice && advice !== a.lastAdvice) await noteAdvice($, cfg, advice)
    } else if (e.text) {
      const p = promptLine(e.text)
      await say($, p.who, p.text)
    }
    return next(e)
  })

  on('turn.step', async function* ($, e, next) {
    // The main loop's model is known when its request starts; a long first request shouldn't read "—".
    if (!e.agentId) {
      let isNewModel = false
      await update($, main, m => {
        const x = normalize(DEFAULT_MAIN, m)
        isNewModel = x.model !== '' && x.model !== e.model
        return { ...x, model: e.model, effort: String(e.effort ?? x.effort), steps: x.steps + 1 }
      })
      if (isNewModel) await update($, usage, x => forgetCompactRead(normalize(DEFAULT_USAGE, x)))
      // Time the response as it passes: its first piece that is neither the engine's envelope nor the
      // stop. One clock read in the stream and nothing stored until it has ended.
      const sentAt = await $.clock.now()
      let firstAt: number | null = null
      const s = next(e)
      for await (const c of s) {
        if (firstAt === null && c.kind !== 'engine' && c.kind !== 'stop') firstAt = await $.clock.now()
        yield c
      }
      const result = await s.result
      const speed = result.usage ? stepSpeed(sentAt, firstAt) : null
      if (speed) await update($, main, m => ({ ...normalize(DEFAULT_MAIN, m), speed }))
      return result
    }
    const id = e.agentId
    // A step from an agent whose card finished means it was resumed (SendMessage): it runs again.
    const before = (await getCards($)).find(c => c.id === id)
    if (before && before.status !== 'running') {
      // Flipped in the write: a resume its agent.spawn already logged is not logged again.
      let isResumed = false
      await update($, agents, list =>
        listOf<unknown>(list)
          .map(normalizeCard)
          .map(c => {
            if (c.id !== id || c.status === 'running') return c
            isResumed = true
            return resumeCard(c)
          }),
      )
      if (isResumed) {
        await say($, await whoIs($, id), 'resumed', 'info', id)
        await refreshStatus($, cfg)
      }
    }
    if (before && before.phase !== 'thinking') {
      await update($, agents, list => listOf<unknown>(list).map(normalizeCard).map(c => (c.id === id ? { ...c, phase: 'thinking' as const } : c)))
    }
    const result = yield* next(e)
    const [cards, a] = await Promise.all([getCards($), getArchitect($)])
    if (cards.some(c => c.id === id)) {
      const step = { model: e.model, usage: result.usage, stopReason: result.stopReason, effort: e.effort, at: await $.clock.now() }
      await update($, agents, list => listOf<unknown>(list).map(normalizeCard).map(c => (c.id === id ? applyStep(c, step) : c)))
      if (result.stopReason === 'max_tokens') await say($, await whoIs($, id), 'hit max_tokens', 'error', id)
    } else if (!a.ids.includes(id)) {
      const now = await $.clock.now()
      await update($, loops, l => stepLoop(listOf<Loop>(l), id, now))
    }
    return result
  })

  on('session.measure', async ($, e, next) => {
    // The compaction window is read once per model window, not on every measurement (a breakdown
    // estimates every category each time): claimed here, in the same write, so no two reads overlap.
    const m = {
      pct: e.context.percent ?? null,
      tokens: e.context.tokens ?? null,
      window: e.context.window,
      costUsd: e.cost?.usd ?? null,
      limits: e.rateLimits.map(limitOf),
    }
    let isStale = false
    // A measurement that changes nothing writes nothing: every write redraws the panes that read usage.
    const stored = await getUsage($)
    if (!isSameMeasure(stored, m) || claimCompactRead(stored, m.window).isClaimed) {
      await update($, usage, x => {
        const claim = claimCompactRead(normalize(DEFAULT_USAGE, x), m.window)
        isStale = claim.isClaimed
        return { ...claim.usage, ...m }
      })
    }
    if (e.changed.includes('context')) await refreshStatus($, cfg)
    const done = await next(e)
    if (isStale) {
      await readCompactWindow($, e.context.window)
      await refreshStatus($, cfg)
    }
    return done
  })

  on('session.compact', async ($, e, next) => {
    const done = await next(e)
    if (!e.agentId && e.trigger !== 'precompute') {
      const now = await $.clock.now()
      await update($, usage, x => {
        const u = normalize(DEFAULT_USAGE, x)
        return { ...u, compactions: u.compactions + 1, lastCompactAt: now }
      })
      await say($, 'main', `context compacted (${e.trigger})`)
    }
    return done
  })

  on('tool.check', async ($, e, next) => {
    const verdict = await next(e)
    if (e.tool_use_id) {
      const check: Check = {
        id: e.tool_use_id,
        tool: e.tool,
        bucket: bucketOf(e.tool),
        verdict: verdict.decision === 'allow' ? 'rule' : verdict.decision,
        inSubagent: Boolean(callLoop.get(e.tool_use_id)),
        detail: shorten(describeInput(e.tool, e.input), 90),
        at: await $.clock.now(),
      }
      await update($, gate, g => recordCheck(normalizeGate(g), check))
      // The status line updates when the call settles; only a refusal ends here.
      if (verdict.decision === 'deny') {
        await say($, 'gate', `denied by rule · ${check.detail}`, 'error')
        await refreshStatus($, cfg)
      }
    }
    return verdict
  })

  on('tool.call', async ($, e, next) => {
    callLoop.set(e.tool_use_id, e.agentId ?? null)
    const text = shorten(describeInput(e.tool, e), 64)
    if (e.agentId && e.tool === 'Skill') {
      const id = e.agentId
      const skill = e.skill
      await update($, agents, list => listOf<unknown>(list).map(normalizeCard).map(c => (c.id === id ? addSkill(c, skill) : c)))
    }
    if (e.agentId && e.tool !== 'Agent' && String(e.tool) !== 'SubagentHandback') {
      const id = e.agentId
      await update($, agents, list => listOf<unknown>(list).map(normalizeCard).map(c => (c.id === id ? { ...c, phase: 'tool' as const, doing: text } : c)))
    }
    const ran = await next(e).finally(() => callLoop.delete(e.tool_use_id))
    const didRun = ran.deny === undefined
    // Settle this call's pending ask, if it had one; skip the write (and the redraw) otherwise.
    const g0 = await getGate($)
    const isSettled = settleCheck(g0, e.tool_use_id, didRun) !== g0
    if (isSettled) await update($, gate, g => settleCheck(normalizeGate(g), e.tool_use_id, didRun))
    // A background agent hands its report back through this tool; an architect's report is its advice.
    if (String(e.tool) === 'SubagentHandback') {
      const message = (e as unknown as { message?: unknown }).message
      const a = e.agentId ? await getArchitect($) : null
      if (a && e.agentId && a.ids.includes(e.agentId) && typeof message === 'string') {
        const advice = adviceLine(message)
        if (advice && advice !== a.lastAdvice) await noteAdvice($, cfg, advice)
      }
      return ran
    }
    if (e.tool === 'Agent') {
      if (isSettled) await refreshStatus($, cfg)
      return ran
    }
    const hasFailed = didRun && ran.isError === true
    const isEdit = !hasFailed && didRun && EDIT_TOOLS.has(e.tool)
    const t0 = await getTurn($)
    if (isEdit || hasFailed || (!e.agentId && t0.errorStreak > 0)) {
      await update($, turn, t => afterCall(normalize(DEFAULT_TURN, t), { inSubagent: Boolean(e.agentId), hasFailed, isEdit }))
    }
    if (e.agentId) {
      const id = e.agentId
      const seenAt = await $.clock.now()
      await update($, agents, list =>
        listOf<unknown>(list)
          .map(normalizeCard)
          .map(c => (c.id === id ? { ...noteTool(c, { tool: e.tool, text, isError: hasFailed || ran.deny !== undefined }), lastAt: seenAt } : c)),
      )
    }
    // The log keeps what is worth a glance: refusals, errors and edits; the rest is on the cards.
    if (ran.deny !== undefined) await say($, await whoIs($, e.agentId), `${text}  denied`, 'error', e.agentId ?? null)
    else if (hasFailed) await say($, await whoIs($, e.agentId), `${text}  ✗`, 'error', e.agentId ?? null)
    else if (isEdit) await say($, await whoIs($, e.agentId), text, 'info', e.agentId ?? null)
    if (isSettled || !didRun) await refreshStatus($, cfg)
    return ran
  })

  // A server-side review tool never reaches tool.call: it shows only in the assistant's rows.
  on('session.append', async ($, e, next) => {
    if (!e.agentId && e.message.type === 'assistant') {
      const a = await getArchitect($)
      // Consults this row opened: their result may be in the same row, after the stale read above.
      const opened = new Set<string>()
      for (const block of e.message.content as unknown as readonly ServerBlock[]) {
        if (block.type === 'server_tool_use' && block.name && block.id && cfg.architect.test(block.name)) {
          if (a.seen.includes(block.id)) continue
          const id = block.id
          await update($, architect, x => {
            const y = normalize(DEFAULT_ARCHITECT, x)
            return { ...y, seen: [...listOf<string>(y.seen), id].slice(-60) }
          })
          opened.add(id)
          await consultStarted($, cfg, id, `${block.name} tool`)
        } else if (block.type.endsWith('_tool_result') && block.tool_use_id) {
          const id = block.tool_use_id
          const isOpen = opened.has(id) || (await getArchitect($)).consults.some(c => c.id === id && c.endAt === null)
          if (isOpen) await consultEnded($, cfg, null, id)
        }
      }
    }
    return next(e)
  })

  // Hard limit on concurrent subagents: the Agent tool's call is refused while `maxAgents` run. Decided
  // one call at a time (makeSpawnGate), so a parallel launch of five still gets its fifth refused.
  const spawnGate = makeSpawnGate()
  on('tool.call', { tool: 'Agent' }, async ($, e, next) => {
    if (cfg.maxAgents > 0) {
      const isAdmitted = await spawnGate
        .admit(e.tool_use_id, cfg.maxAgents, async () => {
          const now = await $.clock.now()
          return { running: agentTotals(await getCards($), now, cfg.agentStaleMs).running, now }
        })
        // A state that cannot be read must never stop the work.
        .catch(() => true)
      if (!isAdmitted) {
        await say($, 'gate', `subagent refused · ${cfg.maxAgents} already running`, 'error')
        return { deny: spawnDenied(cfg.maxAgents) }
      }
    }
    return next(e).finally(() => spawnGate.release(e.tool_use_id))
  })

  on('agent.spawn', async ($, e, next) => {
    const routed = e.resume ? null : routeModel(cfg.agentRoutes, e)
    if (routed) await say($, 'router', `routed ${e.subagentType} → ${routed}`)
    const started = await next(routed ? { ...e, model: routed } : e)
    tick?.cancel()
    tick = $.clock.every(30_000, () => {
      void Promise.all([getCards($), $.clock.now()])
        .then(([cards, now]) => {
          if (cards.some(c => isLive(c, now, cfg.agentStaleMs))) $.ui.invalidate('ui.render')
          else {
            $.ui.invalidate('ui.render')
            tick?.cancel()
            tick = undefined
          }
        })
        .catch(() => undefined)
    })
    if (!e.parentAgentId) await noteMode($, e.permissionMode)
    if (started.deny !== undefined || !started.agentId) return started
    const id = started.agentId
    if (await isArchitectType($, cfg, e.subagentType)) {
      await update($, architect, a => {
        const x = normalize(DEFAULT_ARCHITECT, a)
        return { ...x, ids: [...listOf<string>(x.ids), id].slice(-40) }
      })
      await update($, loops, l => listOf<Loop>(l).filter(x => x.id !== id))
      await consultStarted($, cfg, id, e.subagentType.split(':').pop() ?? 'agent')
    }
    // Every subagent, an architect consult included, gets a card of its own.
    const spawnedAt = await $.clock.now()
    const card: AgentCard = {
      ...normalizeCard({}),
      id,
      type: e.name ?? e.subagentType,
      model: started.model,
      description: e.description,
      spawnedAt,
      lastAt: spawnedAt,
    }
    // Decided in the write: a resume whose first step already put its card back to running is not logged again.
    let isNew = true
    let isResumed = false
    await update($, agents, list => {
      const cards = listOf<unknown>(list).map(normalizeCard)
      const known = cards.find(c => c.id === id)
      isNew = known === undefined
      isResumed = known !== undefined && known.status !== 'running'
      return addCard(cards, card)
    })
    await update($, loops, l => listOf<Loop>(l).filter(x => x.id !== id))
    if (isNew || isResumed) await say($, shorten(cardTitle(card), 12), isNew ? `spawned · ${card.type}` : 'resumed', 'info', id)
    // The card now counts as running; the reservation that held its slot is no longer needed.
    spawnGate.release(e.tool_use_id)
    await refreshStatus($, cfg)
    return started
  })

  on('turn.complete', async ($, e, next) => {
    const done = await next(e)
    const id = e.agentId
    const now = await $.clock.now()
    if (!id) {
      const [t, cards, cost] = await Promise.all([getTurn($), getCards($), costNow($)])
      const r = receiptOf(t, {
        durationMs: e.durationMs,
        agentsSince: cards.filter(c => c.spawnedAt >= t.startedAt).length,
        costNow: cost,
        reason: e.reason,
      })
      await update($, receipt, () => r)
      await update($, main, m => ({ ...normalize(DEFAULT_MAIN, m), isRunning: false }))
      await refreshStatus($, cfg)
      return done
    }
    if ((await getArchitect($)).ids.includes(id)) await consultEnded($, cfg, e.answer, id)
    const cards = await getCards($)
    if (cards.some(c => c.id === id)) {
      const status = e.reason === 'answer' ? 'done' : e.reason === 'aborted' ? 'stopped' : 'failed'
      await update($, agents, list =>
        listOf<unknown>(list)
          .map(normalizeCard)
          .map(c => (c.id === id ? { ...c, status, endedAt: now, answer: shorten(e.answer, 400), phase: null } : c)),
      )
      // This run's own length: a resumed agent's card clock also spans the idle time between runs.
      const took = fmtDuration(e.durationMs)
      await say($, await whoIs($, id), status === 'done' ? `done · ${took}` : status, status === 'done' ? 'done' : 'error', id)
    } else if (!(await getArchitect($)).ids.includes(id)) {
      await update($, loops, l => listOf<Loop>(l).map(x => (x.id === id ? { ...x, isDone: true, lastAt: now } : x)))
    }
    await refreshStatus($, cfg)
    return done
  })

  // ---------------------------------------------------------------- drawing

  // After a surface module faults on a surface, this load draws it there as plain text; the other
  // module, and other surfaces, keep theirs. Keyed by faultKey: `desktop:rail.tsx`.
  const faulted = new Set<string>()
  on('ui.fault', async ($, e, next) => {
    const key = faultKey(e.surface, e.module)
    if (e.requestId === PANE && !faulted.has(key)) {
      faulted.add(key)
      $.ui.log(`flightdeck: ${e.module} faulted on ${e.surface} (${e.phase}: ${e.reason}); drawing it without animation`)
      $.ui.invalidate('ui.render')
    }
    return next(e)
  })

  on('ui.render', { component: 'Pane', requestId: PANE }, async ($, e) => {
    const els = $.ui.resolve(e)
    const { Box, Text, Button } = els
    const hasClient = 'Client' in els
    const hasRail = hasClient && !faulted.has(faultKey(e.surface, 'rail.tsx'))
    const hasClock = hasClient && !faulted.has(faultKey(e.surface, 'elapsed.tsx'))
    const [v, now] = await Promise.all([getView($), $.clock.now()])
    // The body's own width, down to the narrowest dock Claude Code seats (24): a wider drawing is cut off at the frame.
    const W = Math.max(24, e.props.bodyColumns)
    const layout = v.layout ?? cfg.layout

    // A start time of 0 is unknown (state saved before it was recorded): no clock, not decades. A finished
    // item draws its last reading as plain text, so it holds no timer.
    const clock = (key: string, since: number, endAt: number | null, color: string) =>
      since <= 0 ? (
        <Text color={color}>—</Text>
      ) : hasClock && endAt === null ? (
        <els.Client key={key} module="./elapsed.tsx" props={{ since, now, endAt, color }} />
      ) : (
        <Text color={color}>{fmtTimer((endAt ?? now) - since)}</Text>
      )

    const expandOnPress = (id: string) => () =>
      update($, view, x => ({ ...normalize(DEFAULT_VIEW, x), expanded: normalize(DEFAULT_VIEW, x).expanded === id ? null : id }))

    const expandedPanel = (cards: AgentCard[], w: number) => {
      const card = cards.find(c => c.id === v.expanded)
      return card ? (
        <Box flexDirection="column" borderStyle="single" borderColor={C.agent} paddingX={1} width={w}>
          <Text bold wrap="wrap">
            {card.description || card.type}
          </Text>
          <Text dimColor wrap="truncate">{`${card.type} · ${prettyModel(card.model)} · ${card.status} · ${card.steps} steps`}</Text>
          <Text dimColor wrap="truncate">{`skills ${card.skills.join(' ') || '—'}`}</Text>
          {card.tools.length === 0 ? <Text color={C.faint}>no tool calls yet</Text> : null}
          {card.tools.map(n => (
            <Text color={n.isError ? C.warn : C.text} wrap="truncate">
              {`${n.isError ? '✗' : '·'} ${n.text}`}
            </Text>
          ))}
          {card.answer ? (
            <Text dimColor wrap="wrap">
              {`» ${shorten(card.answer, 240)}`}
            </Text>
          ) : null}
        </Box>
      ) : null
    }

    // ---- monitor: reads only the atoms it draws (view above, main, usage, agents), so a gate, architect,
    // turn or log write does not redraw it. No rails.
    if (layout === 'monitor') {
      const [m, u, cards] = await Promise.all([getMain($), getUsage($), getCards($)])
      const inner = W - 4
      const nn = (c: AgentCard) => String(cards.indexOf(c) + 1).padStart(2, '0')
      const running = cards.filter(c => c.status === 'running')
      const ordered = [...running, ...cards.filter(c => c.status !== 'running').reverse()]
      const shown = ordered.slice(0, cfg.maxCards)
      const tones = { thinking: '#f9a8d4', active: C.active, idle: C.agent, done: C.done, failed: C.warn, stopped: C.dim }
      // Emoji take two cells; the rest of the header is one each.
      const cells = (t: string) => [...t].reduce((n, ch) => n + ((ch.codePointAt(0) ?? 0) > 0xffff ? 2 : 1), 0)

      // Header parts dropped from the end as the width narrows: version, then session, then time. The cost stays.
      const costText = `COST: ${u.costUsd !== null ? fmtUsd(u.costUsd) : '$—'}`
      const headAt = (level: number) => {
        const left: { w: number; node: RenderChildren }[] = [
          { w: 15, node: <Text color={C.main} bold>[ CLAUDE CODE ]</Text> },
          { w: cells('🚀 SUBAGENT MONITOR'), node: <Text bold>🚀 SUBAGENT MONITOR</Text> },
        ]
        if (level >= 3) left.push({ w: VERSION.length + 3, node: <Text dimColor>{`(v${VERSION})`}</Text> })
        if (level >= 1) left.push({ w: 2, node: <Text color={C.faint}>──</Text> })
        if (level >= 2 && u.tag) {
          left.push({ w: 10 + u.tag.length, node: <Text>{`SESSION: #${u.tag}`}</Text> })
          left.push({ w: 1, node: <Text color={C.faint}>|</Text> })
        }
        if (level >= 1) {
          left.push({ w: 5, node: <Text>TIME:</Text> })
          left.push({ w: 6, node: clock('monitor-clock', u.startedAt, m.isRunning ? null : now, C.text) })
          left.push({ w: 1, node: <Text color={C.faint}>|</Text> })
        }
        return left
      }
      const level = [3, 2, 1, 0].find(l => headAt(l).reduce((n, p) => n + p.w + 1, 0) + cells(costText) <= W) ?? 0
      const head = (
        <Box width={W} justifyContent="space-between" columnGap={1}>
          <Box overflow="hidden" columnGap={1}>
            {headAt(level).map(p => p.node)}
          </Box>
          <Box flexShrink={0}>
            <Text color={C.text} bold>
              {costText}
            </Text>
          </Box>
        </Box>
      )

      // One gradient bar per limit, at most three.
      const bar = (l: Usage['limits'][number]) => {
        const pct = Math.max(0, Math.min(100, Math.round(l.pct)))
        const reset = fmtResetIn(l.resetsAt, now)
        const base = [shorten(limitLabel(l.kind), inner >= 30 ? 8 : 4), `${pct}%`]
        const withReset = reset ? [...base, `↻${reset}`] : base
        const labelW = (p: string[]) => p.reduce((n, t) => n + cellWidth(t) + 1, 0)
        const parts = inner - labelW(withReset) >= 8 ? withReset : base
        const barW = Math.max(4, inner - labelW(parts))
        const full = Math.round((pct / 100) * barW)
        return (
          <Box width={inner} columnGap={1}>
            <Box flexShrink={0}>
              {Array.from({ length: full }, (_, i) => (
                <Text color={gradientCell(i, barW)}>█</Text>
              ))}
              <Text color={C.faint}>{'░'.repeat(barW - full)}</Text>
            </Box>
            {parts.map((t, i) => (
              <Text {...(i === 1 ? (pct >= 90 ? { color: C.warn } : { color: C.text }) : { dimColor: true })}>{t}</Text>
            ))}
          </Box>
        )
      }
      const usageBox = (

            : `In ${kTokens(inT)} · Out ${kTokens(c.out)}`
        const title = c.type.split(':').pop() ?? c.type
        const isDim = c.status === 'done'
        return (
          <Box flexDirection="column">
            {i > 0 ? <Text color={C.faint}>{'─'.repeat(inner)}</Text> : null}
            <Box width={inner} justifyContent="space-between">
              <Box overflow="hidden" columnGap={1}>
                <Button
                  key={`card-${c.id}`}
                  plain
                  dimColor={isDim}
                  {...(i < 6 ? { hotkey: String(i + 1) } : {})}
                  label={inner >= 34 ? `SUBAGENT_${nn(c)}` : `#${nn(c)}`}
                  onPress={expandOnPress(c.id)}
                />
                <Text color={isMax ? C.warn : tones[st.tone]} wrap="truncate">
                  {`${st.glyph}${inner >= 30 ? ` ${st.word}` : ''}${isMax ? ' ⚠' : ''}`}
                </Text>
                {inner >= 50 ? (
                  <Text dimColor wrap="truncate">
                    {`"${title}"`}
                  </Text>
                ) : null}
              </Box>
              <Box flexShrink={0} marginLeft={1}>
                <Text dimColor={isDim}>{inner >= 34 ? `COST: ${fmtCost3(c)}` : fmtCost3(c)}</Text>
              </Box>
            </Box>
            {row('Model:', c.steps > 0 ? `${prettyModel(c.model)} · effort ${c.effort || '—'} · ctx ${ctx}` : `${prettyModel(c.model)} · starting`, isDim)}
            {row('Task:', c.description ? `'${c.description}'` : '—', isDim)}
            {row('Skills:', c.skills.join(' ') || '—', isDim)}
            {row('Tokens:', tokens, isDim)}
          </Box>
        )
      }

      return (
        <Box flexDirection="column" width={W}>
          {head}
          {usageBox}
          {cards.length === 0 ? (
            <Text color={C.faint}>no subagents yet</Text>
          ) : (
            <Box flexDirection="column" borderStyle="single" borderColor={C.agent} paddingX={1} width={W}>
              {shown.map(card)}
            </Box>
          )}
          {ordered.length > shown.length ? <Text color={C.faint}>{`+${ordered.length - shown.length} more`}</Text> : null}
          {expandedPanel(cards, W)}
          {running.length === 0 ? (
            <Text color={C.faint}>no subagents running</Text>
          ) : (
            running.slice(0, 4).map(c => (
              <Box width={W} columnGap={1} overflow="hidden">
                <Box flexShrink={0}>
                  <Text color={C.active}>{`[SUBAGENT_${nn(c)}]`}</Text>
                </Box>
                <Text dimColor wrap="truncate">
                  {c.doing || '—'}
                </Text>
              </Box>
            ))
          )}
          <Text dimColor wrap="truncate">
            {`flightdeck [${m.isRunning ? 'working…' : 'listening…'}]  ${cards.length > 0 ? `${shown.length > 1 ? `1-${Math.min(6, shown.length)}` : '1'} expand · ` : ''}/flightdeck layout compact`}
          </Text>
        </Box>
      )
    }

    const [m, u, a, g, cards, lp, lines, t, r] = await Promise.all([
      getMain($),
      getUsage($),
      getArchitect($),
      getGate($),
      getCards($),
      getLoops($),
      getLog($),
      getTurn($),
      read($, receipt),
    ])
    const isWide = layout === 'wide' || (layout === 'auto' && W >= 110)
    const colW = isWide ? Math.floor((W - 2) / 2) : W
    const modelName = prettyModel(m.model)
    const viewed = e.props.view?.agentId ?? null
    const advising = isAdvising(a)
    const showArchitect = a.consults.length > 0 || a.ids.length > 0
    const motion = cfg.motion && hasRail
    // A panel with nothing to show yet takes no room: most sessions never spawn an agent.
    const isEmpty: Record<Panel, boolean> = {
      main: false,
      architect: !showArchitect,
      gate: g.recent.length === 0 && gateSummary(g).total === 0,
      agents: cards.length === 0,
      loops: lp.length === 0,
      receipt: !m.isRunning && !r,
      log: false,
    }
    const panels = cfg.panels.filter(p => !isEmpty[p])
    const decider = m.mode === 'auto' ? 'classifier' : 'you'

    // A connector between panels: animated while its flow is live, a dim line otherwise.
    const rail = (key: string, active: boolean, color: string, width: number, marks: number[] = [], isMerge = false) =>
      motion && active ? (
        <els.Client
          key={key}
          module="./rail.tsx"
          width={width}
          height={1}
          props={{ active, width, color, dim: C.faint, marks, isMerge }}
        />
      ) : (
        <Text color={C.faint} mono>
          {'─'.repeat(Math.max(1, width))}
        </Text>
      )

    const isTerminal = e.surface === 'terminal'
    // A row of marks (gate checks, loop dots), sized by `marksIn`. Should a surface draw them wider
    // still, the row is cut at its box rather than running past it.
    const markRow = (marks: RenderChildren, lead = 0) => (
      <Box overflow="hidden" {...(lead ? { marginLeft: lead } : {})}>
        <Text wrap="truncate-start">{marks}</Text>
      </Box>
    )
    // A terminal's border row stands apart from the text above it; a graphical surface draws the
    // border flush against it, so the legend keeps one row of air there.
    const legendGap = isTerminal ? 0 : 1

    // A line of coloured pieces, drawn as a row of boxes the way the log draws its lines. A Text nesting
    // coloured Texts truncates as one line in a terminal, but the desktop app wraps each nested piece on its
    // own, lays truncating ones out as blocks of their own, and collapses runs of spaces. So pieces sit `gap`
    // cells apart (a piece's `lead` adds more), each keeps its width, and pieces that don't fit in `room` are
    // left out from the end; or a piece marked `fill` (one span) truncates to what the others leave.
    type Span = { text: string; color?: string; dim?: boolean; bold?: boolean }
    type Piece = { spans: Span[]; lead?: number; fill?: boolean }
    const styleOf = (s: Span) => ({ ...(s.color ? { color: s.color } : {}), ...(s.dim ? { dimColor: true } : {}), ...(s.bold ? { bold: true } : {}) })
    const widthOf = (p: Piece) => p.spans.reduce((n, s) => n + cellWidth(s.text), 0)
    const line = (pieces: (Piece | null)[], room: number, gap = 1, justify?: 'center') => {
      const all = pieces.filter((p): p is Piece => p !== null)
      const shown = all.some(p => p.fill) ? all : all.slice(0, piecesThatFit(all.map(p => ({ width: widthOf(p), lead: p.lead })), room, gap))
      return (
        <Box width={room} columnGap={gap} overflow="hidden" {...(justify ? { justifyContent: justify } : {})}>
          {shown.map(p => {
            const lead = p.lead ? { marginLeft: p.lead } : {}
            if (p.fill && p.spans[0]) {
              return (
                <Text {...styleOf(p.spans[0])} wrap="truncate">
                  {p.spans[0].text}
                </Text>
              )
            }
            return (
              <Box flexShrink={0} {...lead}>
                {p.spans.length === 1 && p.spans[0] ? <Text {...styleOf(p.spans[0])}>{p.spans[0].text}</Text> : <Text>{p.spans.map(s => <Text {...styleOf(s)}>{s.text}</Text>)}</Text>}
              </Box>
            )
          })}
        </Box>
      )
    }

    // ---- main
    const effortN = { low: 1, medium: 2, high: 3, xhigh: 4, max: 4 }[m.effort] ?? 0
    const ctxFill = contextFill(u)
    const ctxGauge = ctxFill.pct !== null ? gauge(ctxFill.pct, 10) : null
    const mainPanel = (w: number) => (
      <Box flexDirection="column" borderStyle="round" borderColor={C.main} paddingX={1} width={w}>
        <Box justifyContent="space-between">
          <Text color={C.main} bold wrap="truncate">
            {modelName} · main
          </Text>
          <Box flexShrink={0}>
            <Text color={m.isRunning ? C.main : C.dim}>{m.isRunning ? '● working' : '○ idle'}</Text>
          </Box>
        </Box>
        {line(
          [
            {
              spans: [
                { text: 'effort ', dim: true },
                { text: `${'▮'.repeat(effortN) + '▯'.repeat(4 - effortN)} `, color: C.main },
                { text: m.effort || '—', color: C.main, bold: true },
              ],
            },
            m.mode ? { spans: [{ text: `mode ${m.mode}`, dim: true }] } : null,
            { spans: [{ text: `${m.steps} req`, dim: true }] },
          ],
          w - 4,
          3,
        )}
        {ctxGauge
          ? line(
              [
                {
                  spans: [
                    { text: 'ctx ', dim: true },
                    { text: ctxGauge.on, color: ctxFill.pct !== null && ctxFill.pct >= 80 ? C.warn : C.main },
                    { text: ctxGauge.off, color: C.faint },
                    { text: ` ${Math.round(ctxFill.pct ?? 0)}%`, bold: true },
                  ],
                },
                u.tokens !== null ? { spans: [{ text: `${kTokens(u.tokens)}/${kTokens(ctxFill.window)}`, dim: true }] } : null,
                u.compactions > 0 ? { spans: [{ text: `⟲${u.compactions}`, color: C.amber }], lead: 1 } : null,
              ],
              w - 4,
            )
          : null}
        {u.costUsd !== null || u.limits.length > 0
          ? line(
              [
                u.costUsd !== null ? { spans: [{ text: fmtUsd(u.costUsd), color: C.text }] } : null,
                ...u.limits.slice(0, 2).map((l, i): Piece => {
                  const lg = gauge(l.pct, 5)
                  // The time to each reset where the line has room for it: both windows fit from 56 columns,
                  // so a wide pane's half column (59 at 120) has them; a window that doesn't fit is left out.
                  const resetIn = w >= 56 ? fmtResetIn(l.resetsAt, now) : ''
                  return {
                    lead: i > 0 ? 1 : u.costUsd !== null ? 2 : 0,
                    spans: [
                      { text: `${limitLabel(l.kind)} `, dim: true },
                      { text: lg.on, color: l.pct >= 80 ? C.warn : C.main },
                      { text: lg.off, color: C.faint },
                      { text: ` ${Math.round(l.pct)}%${resetIn ? ` ↻${resetIn}` : ''}`, dim: true },
                    ],
                  }
                }),
              ],
              w - 4,
            )
          : null}
        {m.speed ? <Text dimColor wrap="truncate">{`last req  ${fmtSpeed(m.speed)}`}</Text> : null}
      </Box>
    )

    // ---- architect
    const lastConsult = a.consults[a.consults.length - 1]
    const architectPanel = (w: number) => {
      // Both ends are anchors (the first consult, now): should it run past its box, it asks to lose the middle.
      const tl = consultTimeline(a, now, Math.max(8, w - 4))
      return (
        <Box flexDirection="column" borderStyle="round" borderColor={C.arch} paddingX={1} width={w}>
          <Box justifyContent="space-between">
            <Text color={C.arch} bold wrap="truncate">
              {cfg.architectLabel} · {advising ? 'advising' : 'on call'}
            </Text>
            <Box flexShrink={0}>
              <Text>
                <Text dimColor>consults </Text>
                <Text color={C.arch} bold>
                  {a.consults.length}
                </Text>
              </Text>
            </Box>
          </Box>
          <Text color={C.arch} wrap="truncate-middle">
            {tl}
          </Text>
          {lastConsult ? (
            <Text dimColor wrap="truncate">
              {advising
                ? `consulting since ${fmtClock(lastConsult.at)}`
                : `last ${fmtDuration(now - (lastConsult.endAt ?? lastConsult.at))} ago · took ${fmtDuration((lastConsult.endAt ?? now) - lastConsult.at)}`}
            </Text>
          ) : (
            <Text dimColor>not consulted yet</Text>
          )}
          {cfg.moments ? (
            <Box flexWrap="wrap" columnGap={2}>
              {(['before a plan', 'error repeats', 'before done'] as const).map(mo => {
                const isOn = lastConsult?.moment === mo
                return (
                  <Text color={isOn ? C.arch : C.dim} bold={isOn}>
                    {isOn ? '◆' : '◇'} {mo}
                  </Text>
                )
              })}
              <Text color={C.faint}>(inferred)</Text>
            </Box>
          ) : null}
          {a.lastAdvice ? (
            <Text color={C.arch} wrap="truncate">
              » {a.lastAdvice}
            </Text>
          ) : null}
        </Box>
      )
    }

    // ---- gate
    const s = gateSummary(g)
    const verdictColor = (c: Check) =>
      c.verdict === 'rule' ? C.gate : c.verdict === 'cleared' ? C.cleared : c.verdict === 'ask' ? C.amber : C.warn
    const checkMark = (c: Check) => (
      <Text color={verdictColor(c)} dimColor={c.inSubagent}>
        {c.verdict === 'deny' ? '✗' : '■'}

      const totalsOf = (isShort: boolean): Piece[] => [
        { spans: [{ text: '■', color: C.gate }, { text: isShort ? ` ${s.rule}` : ` ${s.rule} allowed`, dim: true }] },
        { spans: [{ text: '■', color: C.cleared }, { text: isShort ? ` ${s.cleared}` : ` ${s.cleared} ${decider}`, dim: true }] },
        ...(s.ask > 0 ? [{ spans: [{ text: isShort ? `■ ${s.ask}` : `■ ${s.ask} pending`, color: C.amber }] }] : []),
        { spans: [{ text: isShort ? `✗ ${s.deny}` : `✗ ${s.deny} denied`, color: s.deny > 0 ? C.warn : C.dim }] },
      ]
      const words = totalsOf(false)
      const isShort = piecesThatFit(words.map(p => ({ width: widthOf(p) })), w - 4, 2) < words.length
      const totals = isShort ? totalsOf(true) : words
      return (
        <Box flexDirection="column" borderStyle="round" borderColor={C.gate} paddingX={1} width={w}>
          <Box justifyContent="space-between">
            <Text color={C.gate} bold wrap="truncate">
              {cfg.gateLabel} · permissions
            </Text>
            <Box flexShrink={0}>
              <Text dimColor>{`${s.total} checks`}</Text>

          {strip.length === 0 ? <Text color={C.faint}>no checks yet</Text> : markRow(strip.map(checkMark))}
          {line([...totals, !isShort && w >= 80 && g.recent.some(c => c.inSubagent) ? { spans: [{ text: 'dim: in subagents', color: C.faint }] } : null], w - 4, 2)}
          {/* Below about 44 columns the three rows' buttons take two lines rather than run past the box. */}
          <Box columnGap={2} flexWrap="wrap">
            {(['file', 'shell', 'other'] as const).map((b: Bucket) => {
              const tl = g.totals[b]
              const n = tl.rule + tl.ask + tl.cleared + tl.deny
              return (
                <Button
                  key={`gate-${b}`}
                  plain
                  hotkey={b[0]}
                  label={`${b} ${n}${open === b ? ' ▾' : ''}`}
                  dimColor={n === 0}
                  onPress={() => update($, view, x => ({ ...normalize(DEFAULT_VIEW, x), gateOpen: normalize(DEFAULT_VIEW, x).gateOpen === b ? null : b }))}
                />
              )
            })}
          </Box>
          {open
            ? g.recent
                .filter(c => c.bucket === open)
                .slice(-5)
                .map(c => (
                  // The verdict sits in a box of its own width, not padded with spaces, which a graphical surface collapses.
                  <Box width={w - 4} columnGap={1} overflow="hidden">
                    <Box width={12} flexShrink={0}>
                      <Text>
                        <Text color={verdictColor(c)}>{c.verdict === 'deny' ? '✗ ' : '■ '}</Text>
                        <Text color={C.dim}>{c.verdict === 'rule' ? 'allowed' : c.verdict === 'cleared' ? decider : c.verdict === 'ask' ? 'pending' : 'denied'}</Text>
                      </Text>
                    </Box>
                    <Text dimColor={c.inSubagent} wrap="truncate">

      )

            <Text bold wrap="truncate">
              {isNarrow ? `agents · ${totals.running}/${limitText}` : `agents · ${totals.running}/${limitText} running · ${totals.total} total`}
            </Text>
            {cards.length > 0 ? (
              <Box flexShrink={0}>
                <Text color={C.faint}>{`1-${Math.min(cards.length, useLanes ? 6 : cfg.maxCards)}${isNarrow ? '' : ' expand'}`}</Text>
              </Box>
            ) : null}
          </Box>
          {cards.length > 0 ? (
            <Text dimColor wrap="truncate">
              {`in ${kTokens(totals.inTok)} · out ${kTokens(totals.out)} · est ${costText}`}
            </Text>
          ) : null}
        </Box>
      )
      if (cards.length === 0) {
        return (
          <Box flexDirection="column" width={w}>
            {header}
            <Text color={C.faint}>no subagents yet</Text>
          </Box>
        )
      }
      if (useLanes) {
        const shown = cards.slice(-6)
        // A lane is its glyph, a label, the bar and a clock, then the model and tokens: on the same row from 80
        // columns, on a row of their own under it below that. Below 34 columns the label narrows, below 36 the bar.
        const isOneRow = w >= 80 && !shown.some(c => c.skills.length > 0)
        const infoW = isOneRow ? 26 : 0
        const extra = isOneRow ? infoW + 1 : 0
        const labelW = Math.min(17, Math.max(7, w - 17 - extra))
        const barW = Math.max(4, w - 11 - labelW - extra)
        const geo = lanes(shown, now, barW)
        return (
          <Box flexDirection="column" width={w}>
            {header}
            {cards.length > shown.length ? <Text color={C.faint}>{`+${cards.length - shown.length} earlier`}</Text> : null}
            {shown.map((c, i) => {
              const gm = geo[i]
              const isViewed = viewed === c.id
              return (
                <Box flexDirection="column">
                  <Box columnGap={1}>
                    <Text color={statusColor(c)} bold={isViewed}>
                      {isViewed ? '▶' : glyph(c)}
                    </Text>
                    <Box width={labelW} flexShrink={0}>
                      <Button key={`card-${c.id}`} plain hotkey={String(i + 1)} label={shorten(cardTitle(c), labelW - 3)} onPress={expandOnPress(c.id)} />
                    </Box>
                    <Box flexShrink={0}>
                      <Text>
                        <Text color={C.faint}>{'·'.repeat(gm?.before ?? 0)}</Text>
                        <Text color={statusColor(c)}>{'━'.repeat(gm?.bar ?? 1)}</Text>
                        <Text color={C.faint}>{'·'.repeat(gm?.after ?? 0)}</Text>
                      </Text>
                    </Box>
                    {clock(`lane-clock-${c.id}`, c.spawnedAt, c.endedAt, C.dim)}
                    {isOneRow ? (
                      <Box width={infoW} flexShrink={0}>
                        <Text dimColor wrap="truncate">
                          {agentInfo(c, infoW)}
                        </Text>
                      </Box>
                    ) : null}
                  </Box>
                  {isOneRow ? null : (
                    <Box marginLeft={2} width={w - 2}>
                      <Text dimColor wrap="truncate">
                        {agentInfo(c, w - 2)}
                      </Text>
                    </Box>
                  )}
                </Box>
              )
            })}
          </Box>
        )
      }
      // One window per subagent, four lines: model · task and status; effort and context; estimated cost and tokens; skills.
      const shown = cards.slice(-cfg.maxCards)
      return (
        <Box flexDirection="column" width={w}>
          {header}
          {shown.map((c, i) => {
            const isViewed = viewed === c.id
            const inner = w - 4
            const isDim = c.status === 'done'
            const tint = isDim ? C.done : C.agent
            const win = cardWindow(c)
            const pct = win > 0 && c.ctx > 0 ? (c.ctx * 100) / win : null
            const cg = gauge(pct ?? 0, 4)
            const stop = c.lastStop === 'max_tokens' ? 'max_tokens' : c.status
            const status = inner >= 30 ? `${glyph(c)} ${stop}` : glyph(c)
            const titleW = inner - cellWidth(status) - 1
            const ctxNums = c.steps > 0 ? `${kTokens(c.ctx)}/${win > 0 ? kTokens(win) : '—'}` : '—'
            const eN = effortLevel(c.effort)
            const effort: Piece = {
              spans: [
                { text: 'effort ', dim: true },
                { text: `${'▮'.repeat(eN) + '▯'.repeat(4 - eN)} `, color: tint },

              ],
            }
            const ctxFull: Piece = {
              spans: [
                { text: 'ctx ', dim: true },
                { text: cg.on, color: (pct ?? 0) >= 80 ? C.warn : tint },
                { text: cg.off, color: C.faint },
                { text: ` ${pct === null ? '—' : `${Math.round(pct)}%`} `, bold: true, dim: isDim },
                { text: ctxNums, dim: true },
              ],
            }
            const ctxShort: Piece = { spans: [{ text: 'ctx ', dim: true }, { text: `${pct === null ? '—' : `${Math.round(pct)}%`} `, bold: true, dim: isDim }, { text: ctxNums, dim: true }] }
            const wideEnough = widthOf(effort) + 2 + widthOf(ctxFull) <= inner
            return (
              <Box
                flexDirection="column"
                borderStyle={isViewed ? 'double' : 'round'}
                borderColor={c.lastStop === 'max_tokens' ? C.warn : C.agent}
                borderDimColor={c.status !== 'running' && !isViewed}
                width={w}
                paddingX={1}
              >
                <Box justifyContent="space-between" width={inner}>
                  <Button
                    key={`card-${c.id}`}
                    plain
                    dimColor={isDim}
                    hotkey={String(i + 1)}
                    label={shorten(`${prettyModel(c.model)} · ${cardTitle(c)}`, titleW - 3)}
                    onPress={expandOnPress(c.id)}
                  />
                  <Box flexShrink={0}>
                    <Text color={c.lastStop === 'max_tokens' ? C.warn : statusColor(c)}>{status}</Text>
                  </Box>

  })
